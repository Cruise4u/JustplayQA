# JustplayQA

A monorepo for testing and prototyping different game projects, all in one place.

## Structure

Each game project lives in its own folder under `projects/`, fully self-contained (its own dependencies, build setup, README, etc.):

```
projects/
  game-one/
  game-two/
```

To add a new project, create a new folder under `projects/` with its own README describing what it is and how to run it.
